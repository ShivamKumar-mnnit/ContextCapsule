Quick Start

1. Wiki server (local dev)

cd capsule-server && npm install && npm run dev

2. Wiki API key

npm run db:seed -- you@email.com

3. Capsule key

Sign up at contextcapsule.ai or run POST /v1/auth/signup on your own instance.

4. Load the extension

chrome://extensions → Developer mode → Load unpacked → wiki-extension/
